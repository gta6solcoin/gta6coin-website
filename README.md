# GTA 6 Coin Website

A static one-page website for gta6coin.xyz.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/banner.png`
- `assets/logo.png`

## Fastest deployment: Netlify
1. Unzip the folder.
2. Go to Netlify and sign in.
3. Drag the entire `gta6coin-website` folder into Netlify's manual deploy area.
4. Add `gta6coin.xyz` under Domain Management.
5. Copy the DNS records Netlify gives you into GoDaddy DNS.

## Vercel
1. Upload these files to a GitHub repository.
2. Import the repository into Vercel.
3. Add `gta6coin.xyz` in Project Settings > Domains.
4. Add Vercel's required DNS records in GoDaddy.

## Editing
All project details and URLs are in `index.html`.
The countdown target is in `script.js`.
